# 教訓ログ

誤り・失敗・ハマりから得た教訓を追記して蓄積する。記録の方針（トリガー・フォーマット・ルールへの昇格）は [`../.claude/rules/lessons-learned.md`](../.claude/rules/lessons-learned.md) を正とする。

- **新しいものを上に追記する**（この見出しの直下）。
- **過去のエントリは書き換えない**。認識が変わったら新しいエントリを追記し、古いエントリから参照する。
- **該当しないものは書かない**（単発のタイプミス、その場限りの試行錯誤、コードやコミット履歴を読めば分かること）。

## 2026-07-26 Vercel のビルドスキップ判定が本番デプロイを恒久的に止めていた

### 概要

`ignoreCommand` に指定したスクリプトが `git diff` の失敗を握り潰し、空の変更リストを「変更なし」と解釈してビルドをスキップしていた。PR #26 以降の本番デプロイが全てスキップされ、コード変更を含む #65 / #67 / #69 が本番へ反映されていなかった。

### 詳細

- **何が起きたか**: `front/scripts/vercel-ignore-docs.sh` が常に「変更なし」を返し、本番デプロイが実行されなくなった。Vercel のデプロイ履歴は `Ignored`（API 上は `CANCELED`）で、失敗として現れなかった。影響期間は PR #26 のマージから発覚まで。
- **なぜ起きたか（根本原因）**: スクリプトが `git diff` の失敗を `|| true` で握り潰していた。Vercel は既定で shallow clone するため比較基準の SHA がローカルに存在せず、`git diff` が失敗してこの経路に入った。空の変更リストは「差分なし」と同じ形になるため、**判定不能がスキップ側に倒れていた**。加えて `HEAD^` を基準にしていたため、一度スキップした変更は次回の判定窓の外に出て、ずれが自己修復しない構造だった。
- **教訓 / 次からどうする**: **失敗の観測可能性が非対称な設定は入れない。** デプロイが走らないミスは「無いものが見えない」形で発覚するが、ビルドスキップのミスは「**古いものが正常に見えている**」形で潜伏する。判定不能は必ず実行側（非 0）に倒し、`|| true` で失敗を握り潰さない。基準 SHA は `HEAD^` ではなく `VERCEL_GIT_PREVIOUS_SHA`（前回"成功した"デプロイ）を使い、基準コミットの存在を `git cat-file -e` で確認する。
- **関連**: [`../.claude/rules/vercel.md`](../.claude/rules/vercel.md) §2（`ignoreCommand` を原則入れない・導入する場合の 4 条件）。upstream `my-custom-skills` PR #131 / #133。

## 2026-07-25 ドキュメントのみの PR でコードレーンの CI が起動していた

### 概要

`dorny/paths-filter` の単一 extglob による除外がスラッシュを跨げず、`.claude/rules/*.md` や `README.md` が除外されなかった。ドキュメントだけの変更でもテスト・ビルドが回っていた。

### 詳細

- **何が起きたか**: ドキュメント・ルールのみの PR で lint / test / build が起動し、CI 時間とキューを消費していた。
- **なぜ起きたか（根本原因）**: `dorny/paths-filter` は**フィルタ内の複数パターンを OR で評価する**ため、「`docs/` でも `.claude/` でも `*.md` でもない」という **AND 条件を表現できない**。回避として書いた単一 extglob `!(docs/**|**/*.md|.claude/**)` は **`/` を跨げない**ため、ネストしたパスが除外対象から漏れた。
- **教訓 / 次からどうする**: **判定を glob マッチャに任せず、変更ファイル一覧への明示的なパターン照合で行う。** `code` は除外リストの否定で求め（新しいディレクトリが増えても黙ってテストが止まらないよう安全側に倒す）、`docs` は対象リストで求める（走りすぎても害が小さいため判断の向きが逆になる）。**判定ロジックを変えたら、スキップ経路を実際に踏む PR で確認する。** 全ジョブが「起動して成功」しても、それはスキップが効いていることの証明にはならない。
- **関連**: [`../.claude/rules/github-actions.md`](../.claude/rules/github-actions.md)「パスフィルタの実装（重要な落とし穴）」。
